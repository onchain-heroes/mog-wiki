En Arcade exploras un laberinto por turnos, recoges botín y avanzas hacia el encuentro final del piso 10.

Usa las **teclas de dirección** para moverte y atacar. Moverse consume Energía, mientras que los ataques normales no cuestan Energía. Si llega a cero, la partida termina.

Observa los patrones de ataque de los enemigos mientras exploras. Aprender cuándo apartarte del peligro ayuda a conservar Energía para los siguientes pisos.

Busca **escaleras** para avanzar. El laberinto cambia entre partidas, así que explora el piso actual en vez de depender de una ruta fija.

Recoge XP para subir de nivel y elige talentos cuando se te ofrezcan. Esas decisiones definen tus capacidades durante el resto de la partida.

Después de derrotar a **Sir Jackalot**, golpea varias veces el gran cofre de recompensa para abrirlo, recoge el botín y usa la salida desbloqueada para terminar la partida.
