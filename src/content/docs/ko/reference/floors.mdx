아케이드는 **10개 층**으로 이어집니다. 층 배너에 현재 진행 상황과 구역이 표시됩니다.

| 층  | 구역         |
| --- | ------------ |
| 1–2 | 시련의 동굴  |
| 3–4 | 독성 늪지    |
| 5–7 | 서리 평원    |
| 8–9 | 보석 빛 심연 |
| 10  | 재칼롯 경    |

계단을 찾아 계속 내려가세요. 도중에 만나는 [특수 방](/ko/reference/encounters/)에서는 에너지를 회복하거나 아이템을 살 수 있습니다.

**성소**는 보스 아레나에 들어가기 전 마지막 준비 장소입니다. 내려가기 전에 준비를 마치세요. 아레나에 들어가면 돌아올 수 없습니다.

이 구역 이름은 **MoG 아케이드**에 해당합니다. 다른 모드나 버전의 층 구성은 다루지 않습니다.

## 층별 적

이 목록에는 직접 등장하거나 소환되는 적과 미믹이 포함됩니다. 만날 수 있는 대상을 설명하며, 매번 모든 적이 등장한다는 뜻은 아닙니다. 적을 선택하면 행동과 대응 방법을 볼 수 있습니다.

<FloorRoster />

## 주변 환경 읽기

[날씨](/ko/reference/hazards/)에 따라 층을 공략하는 방식이 달라집니다. 도착하면 날씨 표시를 확인하세요. [특수 지형과 사물](/ko/reference/cells/)에서는 분수, 가시, 벽 화살, 포탈, 획득물을 설명합니다. 용암 중심부는 후반 층에 등장합니다. 다른 색의 바닥 무늬라고 해서 반드시 접촉 피해를 주는 것은 아닙니다.
