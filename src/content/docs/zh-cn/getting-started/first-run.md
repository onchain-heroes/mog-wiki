在街机模式中，你将探索回合制迷宫、收集战利品，并向第10层的最终战斗前进。

使用**方向键**移动和攻击。移动消耗能量，普通攻击则不消耗。能量降到零时，本次冒险结束。

探索时留意敌人的攻击模式。学会及时离开危险区域，能为后续楼层保留能量。

寻找**阶梯**继续前进。每次冒险的迷宫都会变化，应探索当前楼层，不要依赖固定路线。

收集经验升级，并在出现选项时选择天赋。这些选择会影响本次冒险余下的能力。

击败**杰卡洛特爵士**后，反复攻击大型奖励宝箱将其打开，收集战利品，再从解锁的出口结束本次冒险。

继续阅读[能量与移动](/zh-cn/getting-started/energy/)、[楼层](/zh-cn/reference/floors/)或[天赋](/zh-cn/reference/talents/)。
