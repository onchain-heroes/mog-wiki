一次街机冒险共有**10层**。楼层横幅显示当前进度和所在区域。

| 楼层 | 区域         |
| ---- | ------------ |
| 1–2  | 试炼洞窟     |
| 3–4  | 毒沼         |
| 5–7  | 霜原         |
| 8–9  | 宝光深渊     |
| 10   | 杰卡洛特爵士 |

寻找阶梯继续下行。沿途的[特殊房间](/zh-cn/reference/encounters/)提供恢复能量或购买物品的机会。

**圣所**是进入首领竞技场前的最后准备地点。下行前完成准备；进入竞技场后便无法返回。

以上区域名称适用于**MoG街机模式**。本页不对应其他游戏模式或版本。

## 各层敌人

列表包括直接出现或被召唤的敌人，以及拟态怪物。它说明可能发生的遭遇，不保证每次冒险都会出现所有列出的敌人。选择敌人可查看行为与应对方法。

## 观察环境

[天气](/zh-cn/reference/hazards/)会改变楼层玩法，抵达时请检查天气指示。[特殊地块](/zh-cn/reference/cells/)介绍喷泉、地刺、墙壁飞箭、传送门和掉落物。熔岩中心出现在较深的楼层；其他彩色地面图案不一定会造成接触伤害。
