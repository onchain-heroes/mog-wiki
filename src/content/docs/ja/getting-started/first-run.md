アーケードでは、ターン制の迷宮を探索して戦利品を集め、10階の最後の戦いを目指します。

**矢印キー**で移動と攻撃を行います。移動にはエネルギーを使いますが、通常の攻撃では消費しません。エネルギーがゼロになるとランが終了します。

探索しながら敵の攻撃パターンを観察しましょう。危険から離れるタイミングを覚えると、先の階層に向けてエネルギーを温存できます。

先へ進むには**階段**を探します。迷宮はランごとに変わるため、決まった経路に頼らず、今いる階を探索しましょう。

経験値を集めてレベルを上げ、タレントが提示されたら選びましょう。この選択によって、そのランで使う能力が変わります。

**ジャッカロット卿**を倒したら、大きな報酬の宝箱を何度か攻撃して開けましょう。戦利品を拾い、開いた出口を使うとランが終わります。

続けて[エネルギーと移動](/ja/getting-started/energy/)、[階層](/ja/reference/floors/)、[タレント](/ja/reference/talents/)を確認しましょう。
