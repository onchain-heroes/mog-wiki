アーケードのランは**全10階層**です。階層バナーに現在の進行状況とエリアが表示されます。

| 階層 | エリア           |
| ---- | ---------------- |
| 1〜2 | 試練の洞窟       |
| 3〜4 | 毒の沼           |
| 5〜7 | 霜の平原         |
| 8〜9 | 宝石輝く深淵     |
| 10   | ジャッカロット卿 |

階段を見つけて先へ進みましょう。途中の[特殊な部屋](/ja/reference/encounters/)では、エネルギーを回復したり、アイテムを購入したりできます。

**聖域**はボスアリーナに入る前の最後の準備場所です。アリーナへ入ると戻れないため、降りる前に準備を済ませてください。

ここで紹介するエリア名は**MoGのアーケード**のものです。他のモードやゲーム版は対象にしていません。

## 階層ごとの敵

ここには、その階に直接現れる敵や召喚される敵、ミミックを含めています。遭遇する可能性を示すものであり、毎回すべての敵が現れるわけではありません。敵を選ぶと、その行動と対処法を確認できます。

## 周囲の環境を読む

[天候](/ja/reference/hazards/)によって、その階での立ち回りが変わります。到着したら天候アイコンを確認しましょう。[特殊タイル](/ja/reference/cells/)では、泉、トゲ、壁の矢、ポータル、ドロップを説明しています。溶岩の中心部があるのは下層です。それ以外の色付きの床模様が、すべて接触ダメージを与えるわけではありません。
