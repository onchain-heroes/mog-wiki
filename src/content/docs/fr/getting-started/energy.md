**L’Énergie vous permet de continuer.** À zéro, votre partie se termine.

Vous commencez avec **100 Énergie de base**. Un déplacement normal dans le donjon coûte **1 Énergie**, tandis que les attaques ordinaires n’en coûtent pas. Tenez compte de cette dépense lorsque vous choisissez votre trajet.

Certains effets changent les règles habituelles. Les engelures, par exemple, font consommer de l’Énergie à vos attaques pendant leur durée. Consultez les [effets de la météo](/fr/reference/hazards/) affichés dans l’interface.

Monter en niveau augmente votre Énergie de base. Un [Autel](/fr/reference/encounters/#shrine) permet aussi de dépenser du Trésor pour récupérer de l’Énergie ; vérifiez le soin et le prix affichés avant de confirmer une offrande.

## Déplacements gratuits

Les déplacements sont gratuits dans l’Autel, l’Armurerie et le Sanctuaire, ainsi qu’après la défaite du boss final. Se déplacer pendant le combat contre le boss coûte toujours de l’Énergie.
